目的与范围
RikkaHub 包含一个内嵌的 HTTP 服务器，通过 REST API 公开应用的聊天功能和会话管理。这使得外部客户端（网页浏览器、脚本、其他应用程序）能够通过 HTTP 远程与 AI 聊天系统交互。该 Web 服务器作为 Android 前台服务运行，支持仅本地主机和局域网访问模式，并可选配 JWT 认证。系统还包含一个基于 React 的现代 Web 界面，通过消费这些 API 端点提供桌面级聊天体验。
