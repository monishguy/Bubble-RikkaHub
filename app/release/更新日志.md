# 气泡RH（Bubble RH）版本更新说明

## v1.1（当前版本）

发布日期：2026-08-04

本版本为正式可用版本，包含以下全部功能与修复。

### 新增功能

**会话与消息**

- 会话列表：显示会话名称、自定义头像、最后一条气泡消息预览；支持置顶、删除、下拉刷新与新建会话。
- 新建会话：主界面右下角悬浮按钮可开启全新会话；发送首条消息时自动在服务器创建，新会话可直接命名。
- 气泡拆分：AI 与用户消息均按设定的分隔符（默认 `#` / `*`）拆分为多个气泡，不含分隔符的消息按单气泡显示。
- 消息时间：间隔较长的消息间显示时间，非当天显示日期，非当年附带年份。
- 长按复制：长按任意气泡弹出菜单复制内容。
- 跳到底部：上翻查看历史消息时，右下角显示"跳到底部"按钮，一键回到最新消息。

**个性化定制**

- 会话信息：全屏编辑界面，可设置会话昵称、Emoji、头像图片与自定义聊天背景（图片或颜色）。
- 我的资料：在设置页设置自己的昵称、Emoji 与头像，显示在右侧气泡旁。
- 助手自定义：助手切换列表中可为每个助手设置自定义名称、Emoji 与头像，按助手 ID 保存在本地，不受服务器刷新影响。
- 头像显示模式：每条显示 / 仅首条显示 / 仅末条显示。
- 气泡动画：可自定义起始缩放、动画时长、回弹效果与强度。
- 气泡弹出延迟：可设置多气泡逐个弹出的随机延迟范围。
- 列表样式：平铺列表 / 圆角卡片。
- 自动格式提示词：新对话首条用户消息前自动添加格式说明（内容可自定义、可恢复默认、`{start}`/`{end}` 变量自动代入分隔符，提示词不会在聊天界面显示）。

**助手切换**

- 支持切换 RikkaHub 中的助手，切换后会话列表自动刷新为该助手下的会话。

**离线与可靠性**

- 本地缓存：已打开的会话缓存消息，重新进入秒开并直接定位到最新消息，仅增量更新。
- 离线提示：服务器离线时主界面顶部显示红色提示条，仍可查看缓存聊天记录。
- 发送队列：网络异常或服务器繁忙时消息进入本地队列，网络恢复后自动补发。
- 自动刷新：前台/后台按设定间隔自动检测新消息与新会话，并有常驻保活服务。

**通知与未读**

- 未读计数：按新消息拆分出的气泡数统计，列表项显示未读徽标。
- 已读持久化：打开过的会话记录已读时间，刷新后不重复显示未读。
- 消息通知：收到未读消息时推送通知，使用自定义昵称与头像；点击通知直达对应会话。
- 常驻保活通知：后台同步服务显示静音常驻通知。

**其他**

- 配置导入导出：全部配置（服务器地址、分隔符、发送/头像模式、气泡延迟、动画参数、提示词、我的资料等）可导出为 JSON 或从文件导入。
- 深色模式与动态取色：跟随系统，支持 Material You 主题色。
- 应用名称：中文环境显示「气泡RH」，英文环境显示「Bubble RH」。

### 修复与优化

- 修复 SSE 流读取挂起问题：改用原生 HttpURLConnection 读取事件流，解决助手列表与实时消息获取失败。
- 修复消息发送失败（HTTP 500）：正确序列化 `type` 字段，5xx 自动重试，4xx 显示真实错误。
- 修复应用启动崩溃：前台服务改为前台状态启动，DataStore 改为顶层单例。
- 修复用户消息刷新后分隔符重现、气泡无法识别的问题。
- 修复会话列表顶部大片空白、输入框文字重叠、键盘弹出黑块等问题。
- 修复通知点击无法进入对应会话的问题。
- 修复切换助手后原助手缓存被误删、切回时从头加载的问题：现在仅清理当前助手已删除的会话，其他助手的缓存保留。
- 优化新建会话首轮对话的加载与提示词处理，避免重复加载与误显示。
- 优化气泡弹出动画与重进会话定位到最新消息；上翻消息时不再被新消息强制拉回底部。
